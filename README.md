# Loop Parallelization Hint Detector (Flang/FIR)

## Overview

This project implements a Loop Parallelization Hint Detector for Fortran programs using FIR (Fortran Intermediate Representation) generated by Flang.

The detector analyzes `fir.do_loop` constructs and identifies dependency patterns that may prevent loop parallelization. Based on the detected dependencies, each loop is classified as:

* Likely Parallelizable
* Not Safe

## Features

* Detects `fir.do_loop` constructs in FIR
* Identifies common dependency patterns
* Classifies loops automatically
* Supports multiple loops in a single program

## Dependency Types Detected

### 1. Array Dependency

Example:

```fortran
a(i) = a(i-1) + 1
```

Detected using:

```text
arith.subi
```

### 2. Loop-Carried Dependency

Example:

```fortran
x = x + i
sum = sum + a(i)
```

Detected using:

```text
fir.load %X
...
fir.store ... to %X
```

### 3. I/O Dependency

Examples:

```fortran
print *, i
write(10,*) a(i)
```

Detected using:

```text
_FortranAio
```

### 4. Function Side Effect Dependency

Example:

```fortran
call update_global(i)
```

Detected using:

```text
fir.call
```

## Project Workflow

```text
Fortran Source
      ↓
Flang
      ↓
FIR (.mlir)
      ↓
Loop Parallelization Hint Detector
      ↓
Safe / Unsafe Classification
```

## Build

```bash
mkdir build
cd build

cmake ..
make
```

## Generate FIR

```bash
flang-new -fc1 -emit-fir tests/safe.f90 -o tests/safe.mlir

flang-new -fc1 -emit-fir tests/unsafe.f90 -o tests/unsafe.mlir
```

## Run

```bash
./detector ../tests/safe.mlir

./detector ../tests/unsafe.mlir
```

## Sample Output

```text
Loop #1
Classification : Not Safe
Reason : Array Dependency

Loop #2
Classification : Not Safe
Reason : Loop-Carried Dependency
```

## Assumptions

* Dependency detection is heuristic-based.
* FIR is analyzed as text generated by Flang.
* The detector focuses on common dependency patterns rather than full data-flow analysis.
